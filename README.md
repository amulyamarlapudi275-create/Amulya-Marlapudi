
# Shalem Prayer House

A bilingual (Telugu and English) digital church platform designed to strengthen believers and connect the church community.

## Project Vision

Designed with a vision to strengthen believers in the Lord.

## Main Applications

- Mobile Application – Flutter
- Admin Web Dashboard – Next.js
- Christmas QR Event Website – Next.js
- Backend API – NestJS
- Database – PostgreSQL

## Main Modules

1. Home
2. Bible and Spiritual Growth
3. Church Community
4. Member Profiles
5. Church Administration
6. Church Calendar and Events
7. Notifications
8. Offline Resources
9. Christmas QR Experience

## Technology

- Flutter
- Next.js
- NestJS
- PostgreSQL
- Firebase Cloud Messaging
- Git and GitHub

## Languages

- English
- Telugu

## Development Principles

- Security and privacy first.
- Role-based access control.
- Offline support.
- Modular architecture.
- Accessible and simple user experience.
- Reliable data backup and recovery.
